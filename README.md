# WildTracks — Global Geospatial Framework

**WildTracks** is a spatial intelligence platform that predicts the probability of encountering a species at any location in the world. It is designed for hunters, anglers, and foragers.

## Key Features
- **150+ GB Database:** PostgreSQL/PostGIS with 96M+ landscape features and 4M+ iNaturalist observations.
- **Multi-Factor Algorithm:** Considers climate, altitude, seasonality, time of day, and lunar phases.
- **Explainable AI:** Shows exactly which environmental factor is the bottleneck.
- **Safety Module:** Identifies poisonous mushrooms and dangerous wildlife.

## Tech Stack
- **Backend:** PHP 8 (Symfony), PostgreSQL 15, PostGIS.
- **Frontend:** Leaflet.js, JavaScript, HTML/CSS.
- **Data:** OpenStreetMap, iNaturalist API, WWF Ecoregions.
